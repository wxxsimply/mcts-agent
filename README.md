项目名称：mcts-agent (基于 MCTS 的深度推理智能体)
1. 解决的核心痛点
   传统 LLM 在处理复杂逻辑、数学证明或多步骤编程任务时，常面临“线性思维”导致的幻觉问题，即一旦中间步骤出错，后续结果全盘皆错。本项目通过引入搜索机制，解决了 LLM 缺乏自纠错能力和非线性思考的痛点，将 AI 从“凭直觉回答”提升为“靠搜索推理”。

2. 核心逻辑流：长链推理与闭环验证
   项目核心并非简单的对话，而是基于 MCTS（蒙特卡洛树搜索） 演化出的长链推理流：

思维树搜索：利用 mcts/search.go 实现状态空间的深度探索，将复杂问题拆解为多个决策分枝。

长链推理：Agent 不再给出单一答案，而是在多条逻辑链条中反复模拟与评估。

闭环执行验证：集成 runner/exec.go 模块，通过实时执行代码获取反馈，利用运行结果（如报错或成功）作为搜索评价指标，实现了“推理-尝试-修正”的闭环协作逻辑。
